# Fidelis Takyi Mensah - Portfolio Website

Personal portfolio website for **Fidelis Takyi Mensah**, Software Engineer & Frontend Engineer.

## Tech Stack
- **HTML5 & CSS3** (Custom properties, responsive flexbox & grid)
- **JavaScript (ES6+)**
- **AOS (Animate On Scroll)**
- **Swiper.js** (Touch-enabled slider)
- **Kursor.js** (Custom animated cursor)

## Setup & Local Development
Simply open `index.html` in any web browser, or serve using a local development server (e.g., Live Server or `npx serve`).

## Contact & Formspree Configuration
To connect the contact form to your own email:
1. Sign up or log into [Formspree](https://formspree.io).
2. Create a new form and copy your form ID / URL (`https://formspree.io/f/<your-form-id>`).
3. Replace `YOUR_FORMSPREE_ID` in `index.html` with your form endpoint.
